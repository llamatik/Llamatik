Share this device new in 2.0

Every device you own,
one shared brain.

Your gaming PC has the horsepower. Your phone has you. Turn on Share this device and Llamatik serves your loaded models to your other devices over the local network — found automatically with mDNS.

  • Approve each device before it can use yours — no shared secrets to leak.
  • Hands-off discovery. Nearby Llamatik hosts show up on their own.
  • Resilient streaming. Drop off Wi-Fi mid-answer and it reconnects and continues.
  • Android, Desktop and iOS can host. Your battery thanks you.

Connections between devices are currently plain HTTP — keep them on networks you trust.

val agent = Agent {
    name("Kotlin Assistant")
    systemPrompt("You are an expert Kotlin developer.")
    temperature(0.7f)
    memory(SlidingWindowMemory(windowSize = 20))
    tools { builtIns() }   // calculator, date/time, uuid, random
}

agent.stream("What is 17% of 2,340?").collect { chunk ->
    when (chunk) {
        is AgentStreamChunk.Delta -> print(chunk.text)
        is AgentStreamChunk.Done  -> println()
        else -> Unit
    }
}
val path = LlamaBridge.getModelPath("phi-2.Q4_0.gguf")

    topP = 0.95f, topK = 40, numThreads = 4,
)
LlamaBridge.initGenerateModel(path)

Llamatik Server

Your own inference backend.
Same API. Zero code changes.

Need more power than a phone? Self-host a Ktor server that speaks exactly the same API as the library — text, embeddings, speech, images, video and vision, streamed over SSE.

  • Full LlamaBridge, WhisperBridge, StableDiffusionBridge and MultimodalBridge parity
  • Schema-constrained JSON, KV sessions, speculative decoding, GPU offload
  • JWT auth, profiles, Docker-ready — or embed com.llamatik:server in your own app
